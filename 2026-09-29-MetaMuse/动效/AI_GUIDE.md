# 给 AI 模型的说明：用这个模板做一期新视频

> 这份文档写给要改这个模板的 AI 编程助手（也欢迎人读）。先完整读完再动手。

## 你要做的事
用户会给你两样东西：**一份口播字幕（SRT）** 和 **这期要讲的内容 / 数据 / 出处**。你要产出的是 `src/episode/` 下的一套新分镜，让画面跟着口播逐字出现。**`src/engine/` 是引擎，一般不用改**；需要新组件时，先看 `engine/kit.tsx` 里有没有能用的。

## 目录
```
src/
  engine/          引擎 (与内容无关)
    config.ts      设计基准: 帧率 50、画面 1920×1080 (要更高分辨率用渲染参数 --scale, 别改这里)
    timeline.ts    口播时间轴: 第 n 句 / 第 n 句里某个词 → 帧号
    Episode.tsx    一期视频的总装: 分屏切换、人物、底部字幕条、右上角章节提示、音效轨
    kit.tsx        版面组件库 (见下方「组件速查」)
    media.tsx      素材: 图片 / 图标 / 演示视频 (src 留空时画占位块)
    anim.ts        动画数学: prog / spr / env / count / E(缓动)
    ui.tsx         Rise 飘入 / Phone 手机外框 / Stagger 逐字出现
    icons.tsx      Brand 品牌徽章 (首字母, 不画真实 Logo)
    fonts.ts       字体
  episode/         一期的内容 (照着改这里)
    lines.ts       字幕 (由 SRT 生成, 不要手写)
    time.ts        时间轴实例 + 片长 + 跳剪点
    pages1-3.tsx   分镜页, 每页一个组件 + 一条 PageDef
    index.ts       把分镜、章节、素材装成一期
    assets.tsx     这期用到的外部素材路径 (留空 = 占位块)
    brands.ts      这期提到的产品 / 平台名 (画成首字母徽章)
    sfx_trim.json  各音效的音量修正
```

## 第一步：字幕 → 时间轴
```bash
npm run lines -- 你的字幕.srt      # 生成 src/episode/lines.ts (npm 传参要加 --)
```
然后改 `src/episode/time.ts` 里的 `DURATION`（片长帧数 = 秒数 × 50）和 `CUTS`（口播底片的跳剪点帧号，没有就写 `[]`）。
**语音识别的字幕常有错字，先改对 SRT 再转**：`at()` 按字找词，错一个字就会报错。

## 第二步：写分镜页
每一页 = 一个 React 组件 + 一条 `PageDef`：
```ts
{ id: 'P05', a: 1010, b: 1352, mode: 'split', C: P05, sfx: P05cues }
```
- `a` / `b`：这一页的起止帧。引擎用它决定人物窗什么时候展开 / 收起、自动音效什么时候响。**页面组件里的 `Shell` / `SideCard` 也各有一对 `a` / `b`，决定内容什么时候显示，两处必须一致**（改一处忘了另一处，版面会和人物窗错开）。建议把每页的起止帧写成一个常量，PageDef 和组件共用。
- `mode`：
  - `split`：左边版面（宽 1200），右边人物竖幅。**最常用**。
  - `full`：人物全屏，左上角叠一张 `SideCard` 信息卡。适合开场、情绪句、不需要看图的段落。
  - `take`：整屏章节卡（`Chapter`），盖住人物，用于章节切换。
- `sfx`：这一页的音效点 `[{ f: 帧号, s: 音效名, v: 音量 }]`，音效名见 `public/sfx/`。分屏展开 / 收起的「嗖」声是自动加的，不用写。

### 元素的出现时刻用口播定位，不要等间距排
```ts
import { at, LF, LT } from './time';
LF(14)            // 第 14 句开始的帧
LT(14)            // 第 14 句结束的帧
at(13, 'Muse')    // 第 13 句里「Muse」开始念出的帧 (句内按字数估算)
at(13, 'Muse', 1) // 第 2 次出现的「Muse」
```
说明：示例里**页面的起止帧**（PageDef 和 Shell 的 a/b）有不少是在 Studio 里对着原片口播调出来的具体数字（例如 P05 的 1010 / 1352），**元素的出现时刻**则大多用 `at()` / `LF()`。换了一份字幕后，`at()` / `LF()` 会自动跟着走，但这些写死的数字不会，要逐页重新定（最好改成 `LF(n)` 这类写法）。

示例（`episode/pages1.tsx` 的 P05 目录页）：四行各自在念到那一项时出现，高亮跟着「当前念到第几项」走，每行出现时配一声 tick：
```tsx
const TOC = [
  { n: '01', t: 'Muse 能用来干什么', a: at(13, 'Muse') - 6 },
  { n: '02', t: 'Meta 为什么要做', a: LF(14) },
  ...
];
const P05cues: Cue[] = TOC.map((r) => ({ f: r.a, s: 'tick', v: 0.35 }));
```

### 页面骨架
- 分屏页用 `Shell` 包起来：`<Shell a={..} b={..} kicker="英文小标 ｜ 中文小标" title="一句话标题" source="来源: xxx 2026-09-22">…</Shell>`。版面左边距 `X0 = 110`，右边界 `X1 = 1110`，标题下粗线在 y = 236，内容从 y ≈ 262 往下排，出处默认在 y = 894。
- 全屏页用 `SideCard`：`<SideCard a={..} b={..} kicker="…">…</SideCard>`，分屏没收完时它会自动隐藏，不会和版面叠在一起。
- 底部 110 像素是字幕条（`BAR_H`），**不要把任何东西放进去**。

## 组件速查（`engine/kit.tsx`）
| 组件 | 用途 | 关键参数 |
|---|---|---|
| `Title` `Body` | 标题 / 正文 | `size`（Body 另有 `color` `weight`） |
| `Kicker` `Note` | 英文小标 / 出处小字 | 只有 `style`，改字号用 `style={{ fontSize }}` |
| `In` | 整块上浮淡入 | `at` 出现帧, `dy` `dx` |
| `Pop` | 弹簧弹出 | `at` |
| `Hair` | 画一条横线 | `x y w at` |
| `Strike` | 删除线（念到「不是…」时划掉） | `at` |
| `Card` | 卡片 | `x y w h at hot tone` |
| `Stat` | 大数字 + 说明 | `v unit label` |
| `Chip` | 胶囊标签 | `tone` |
| `Bars` | 条形图（每行各自入场） | `rows: [{name, v, unit, at, hot}]`, `max` |
| `VTimeline` | 竖向时间线 | `items: [{date, text, at, hot}]` |
| `Steps` | 横向流程框 + 箭头 | `items: [{t, at, hot, tone}]` |
| `Quote` | 引语：英文原话 + 中文意思 + 出处 | `en zh who at zhAt` |
| `Donut` | 环形图 | `pct at` |
| `PhoneBox` + `RemapClip` | 手机壳里放演示视频，并把源片时间重映射到口播上 | `keys: [[合成帧, 源片秒], …]` |
| `Ring` | 高亮框（套在演示画面的某个按钮上） | `x y w h at` |
| `AppTile`（kit）/ `Logo`（media） | App 图标（没有图片时显示首字母） | `src letter size` |
| `Brand`（icons） | 产品 / 平台的首字母徽章（在 `episode/brands.ts` 登记名字） | `icon={{ title }} size color` |
| `Chapter` | 整屏章节卡 | `a b n title sub` |

动画数学（`engine/anim.ts`）：`prog(frame, a, b)` 是 a→b 帧的 0..1 进度（带缓动），`spr(frame, start)` 是弹簧，`env(frame, a, b)` 是淡入淡出包络，`count(frame, a, b, to)` 是数字滚动。

## 素材
所有外部素材在 `episode/assets.tsx` 里登记，**留空就是占位块**（斜纹方块 / 首字母图标 / 带时间码的人形剪影），所以没有素材也能完整预览和渲染。有素材时把文件放进 `public/media/`，填相对 `public/` 的路径。
**不要替用户去网上找别人的图片、视频、Logo 放进来**；需要什么素材，列出来请用户自己提供。

## 内容规矩（这套风格是按这些规矩调出来的，改分镜时照做）
1. **逐句锚定**：每个元素都要在口播念到它的那一刻出现，用 `at()` / `LF()` 定时间。**不要一整页内容一次性铺出来，也不要用固定间隔错峰。**
2. **屏幕只放骨架**：字幕已经逐字显示了口播，屏幕上只写关键词、数字、结构关系，不要把口播原句再抄一遍。检验方法：把屏幕文字念出来，如果和口播几乎一样，就是没提炼。
3. **一页最多 3 种字号**（主 / 次 / 标签），最好 2 种。同级内容同字号。
4. **讲机制要演过程**：如果这段口播描述的是一个连贯动作（先做 A 再做 B），就让画面演一遍；如果是一份清单，就老实用文字列表。动画进度要跟着口播节拍走，讲到第几步才走到第几步。
5. **不编数字，不编内容**：画面上的每个数字都要能在口播稿或用户给的资料里找到出处，并在 `source` 里写明来源和日期。示意用的图形可以有，但别给它标数字。示例里的名字、内容换成代号不丢信息的，就用代号。
6. **引语用原话**：`Quote` 放英文原话 + 中文意思 + 说话人和出处，不要改写后当原话。
7. **排版约定**：屏幕文案不用间隔点「·」和破折号「——」，用逗号、冒号或直接连写。
8. **字幕带上方不压东西**：底部字幕条 110 像素内不放任何元素。

## 做完一页就看图检查（最重要）
代码能编译不代表画面对。每写完或改完一页，**渲几张静帧亲眼看**：
```bash
npm run still -- Ep32 out/check 1100,1200,1300    # 渲指定帧, 默认半分辨率
```
重点看：元素是不是在该出现的那个字出现、有没有压到字幕条、文字有没有溢出卡片、有没有两样东西叠在一起、同级文字字号是否一致。
**如果你（模型）看不了图片，就把静帧交给用户看**，不要假设画面没问题。

## 常见坑
- 新增 `Sequence` / `Audio` / `Video` / `OffthreadVideo` / `Img` / `AbsoluteFill` 时都加 `showInTimeline={false}`：不加的话，在 Remotion Studio 时间轴上误拖一下会直接改写源码。
- `at()` 找不到词会直接报错（这是故意的，防止写错字悄悄错位）。报错时先检查字幕里这个词是怎么写的。
- 页面的 `a..b` 之外组件返回 `null`；相邻两个分屏页间隔 ≤30 帧时，人物窗不会收起来再展开（引擎自动合并），所以连续讲解的页尽量首尾相接。
- 中文字体裁剪到了 GB2312 常用字和常用符号，生僻字和少数符号（例如短横线「–」）会缺字、掉到系统字体。需要时从 Google Fonts 下载完整版 Noto Sans SC / Noto Serif SC，替换 `public/fonts/` 里的同名文件。
- `RemapClip` 的 `keys` 至少要有一个 `[合成帧, 源片秒]`。
- 每个音效最多播 6 秒（`engine/Episode.tsx` 的 `SFX_MAX`），加更长的音效时调大。
- 不要改 `engine/config.ts` 的帧率和分辨率：版面坐标按 1920×1080 设计，分镜帧号按 50 帧写。
- 渲染：`npm run render` 出 1920×1080；要 2K 用 `npm run render -- --scale=1.3333333333333333`（刚好 2560×1440，注意 npm 传参要加 `--`）。
